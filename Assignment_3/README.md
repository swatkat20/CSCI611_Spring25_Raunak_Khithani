To run the model - use colab.ipynb and modify the path of testing videos as per the directory of your system.

Dataset and output are at:
https://drive.google.com/drive/folders/1McgboTitWqP0DmTXiCo_IlU0iFHKQmwS?usp=drive_link

Under data folder:
In ts folder: There is training and testing data
In train.txt: The files to be included in training
In test.txt: The files to be included in testing

In testVideos there are the videos on which I tested the model and have submitted the results under outputVideos folder.

Modify path in ts_data.yml as per the directory of your system.
